# LastBag App Icon — Design Spec

Use this spec when commissioning or redrawing the production icon. The repo includes programmatic placeholders generated by `scripts/generate-icons.py`.

## Concept

- **Background:** Solid LastBag terracotta `#D85A30` (iOS/Android full icon only — not in foreground layers).
- **Mark:** Single white shape combining a **leaf** (top) with a **rescue bag / bowl** silhouette (bottom). One continuous form, no outlines, no text.
- **Style:** Flat, geometric, high contrast. Must read clearly at 29×29px (iOS notification) and Android adaptive icon safe zone.

## Geometry

| Asset | Canvas | Mark placement |
|-------|--------|----------------|
| `icon.png` | 1024×1024, opaque terracotta fill | Mark ~56% of canvas, centered |
| `android-icon-foreground.png` | 1024×1024, **transparent** | Mark within inner **66%** safe circle |
| `android-icon-background.png` | 1024×1024, solid `#D85A30` | No mark (color only) |
| `android-icon-monochrome.png` | 1024×1024, **transparent** | White mark only (themed icons) |
| `splash-icon.png` | 1024×1024, **transparent** | White mark ~52% of canvas |
| `favicon.png` | 48×48, opaque terracotta | Simplified mark ~52% |

## Do / Don't

- ✅ Flat vector look, generous padding, centered
- ✅ Same mark across all assets (scale only)
- ❌ No wordmark, no “LastBag” text, no gradients on the mark
- ❌ No rounded corners on `icon.png` (stores mask automatically)
- ❌ No transparency on `icon.png`

## Regenerate placeholders

```bash
python3 scripts/generate-icons.py
```

## Expo config

Paths are wired in `app.json` under `expo.icon`, `expo.splash`, `expo.android.adaptiveIcon`, and `expo.ios.icon`.
